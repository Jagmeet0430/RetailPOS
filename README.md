# RetailPOS

RetailPOS is a modern retail point-of-sale and inventory management
application inspired by established desktop POS workflows.

## Goals

- Extremely fast checkout
- Simple enough to learn within five minutes
- Reliable offline/local operation
- Professional inventory management
- Barcode scanner support
- Receipt printing
- Customer and supplier management
- Role-based security
- Detailed reporting
- Modular architecture for future cloud and AI features

## Applications

### Desktop
Electron + React + TypeScript

### API
FastAPI + Python

### Database
PostgreSQL
