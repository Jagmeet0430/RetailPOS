The next design decision is the core PostgreSQL schema. Begin with these entities:

- Store
- User
- Role
- Permission
- Product
- Category
- Unit
- Barcode
- Customer
- Supplier
- Sale
- SaleItem
- Payment
- Purchase
- PurchaseItem
- Inventory
- StockMovement
- Tax
- Discount
- CashRegister
- CashSession
- Return
- ReturnItem
- AuditLog

Before writing SQL, define why each table exists, required columns, primary keys, foreign keys, relationships, indexes, and constraints.
