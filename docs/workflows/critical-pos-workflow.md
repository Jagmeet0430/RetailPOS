# Critical POS Workflow

This is the heart of the application.

1. Cashier logs in.
2. Open POS.
3. Scan barcode or search product.
4. Product is added to cart.
5. Change quantity if needed.
6. Apply discount if allowed.
7. Select customer, if needed.
8. Click PAY.
9. Select payment method: cash, card, UPI, or other.
10. Complete transaction.
11. Create sale record.
12. Create sale items.
13. Create payment record.
14. Reduce stock.
15. Create inventory movement.
16. Create audit log.
17. Print receipt.
18. Prepare for the next customer.

The POS workspace should minimize clicks and support product lookup, payment actions, receipt printing, and stock tracking.
